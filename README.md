# 前端选型 + 高质感 UI 技能

说一句"我想做个 XXX"，它就用 ≤4 个选项式问题了解需求，给出 1 个最佳 + 1 个备选的技术栈与视觉风格，输出含具体色值、字体、圆角的设计简报，再辅助做出高质感成品，交付前自动按质量清单与反 AI 模板清单自检。

## 安装

把 `frontend-design-advisor/` 整个目录放到以下任一位置：

| 位置 | 生效范围 |
|---|---|
| `~/.claude/skills/` 或 `~/.commandcode/skills/` | 你的所有项目 |
| 项目根目录 `.claude/skills/` 或 `.commandcode/skills/` | 仅该项目（可随仓库提交给团队） |

装完重启会话即可自动发现，也能用 `/frontend-design-advisor` 手动触发。

平台不支持技能时：把 SKILL.md 正文当系统提示词用，`references/` 当知识库附上。

## 触发语示例

- 「我想做一个驾考刷题软件」
- 「帮我做个 AI 写作工具」
- 「要给产品做个宣传首页，要科技感」
- 「前端用什么？页面想要高级一点」

## 如何更新知识库

1. **季度核实**：用 GitHub 接口核对 `references/component-sources.md` 里各仓库的星标数与维护状态，把"核实于 YYYY-MM"改成新日期
2. **扩充风格库**：遇到喜欢的页面，把"对标产品 + 提取的参数（色值/圆角/字体）"追加到 `references/style-library.md`
3. **记录偏好**：多次选择同类风格后，在下方"个人偏好"记一条，之后默认优先推荐
4. **反馈迭代**：哪次做得不满意，把原因归纳成新条目写进 `references/anti-patterns.md`
