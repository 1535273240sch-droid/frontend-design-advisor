# 风格库

> 每种风格给出：一句话气质、对标锚点、适用场景、可落地参数。
> 以下色值是起点，不是终点——需按具体产品调整主色，避免"所有产品一个样"。

## 1. Linear / Dark Minimal（极客暗色极简）
- 气质：冷静、专业、信息密度高
- 对标：Linear.app、Raycast、Vercel
- 适合：开发者工具、AI 工具、效率类 SaaS
- 参数：
  - 背景 #0A0A0A（页面）/ #111113（卡片）
  - 边框 1px，rgba(255,255,255,0.08)
  - 文字 #EDEDED（主）/ #8A8F98（次）
  - 圆角 6–8px；阴影基本不用，靠边框和明度分层
  - 字号偏小（13–14px 正文），字重 400/500，标题字距略收紧

## 2. Bento Grid（便当盒栅格）
- 气质：产品功能一目了然，精致、有层次
- 对标：Apple 产品页、Linear 首页
- 适合：落地页功能介绍、仪表盘首页
- 参数：
  - 不等大的卡片严格对齐在同一网格（如 12 列），间距统一 12–16px
  - 圆角 16–24px，**不同层级可用不同圆角**，避免一刀切
  - 每个卡片只讲一件事，有一张是视觉主角（更大、更有画面）

## 3. Glassmorphism（毛玻璃）
- 气质：通透、轻盈、现代
- 对标：macOS Big Sur 之后、iOS 控制中心
- 适合：浮层、弹窗、侧边栏、音乐/天气类应用
- 参数：
  - 半透明背景 rgba(255,255,255,0.08–0.18) + backdrop-filter: blur(16–24px)
  - 1px 半透明白色描边；背景必须有彩色渐变或图像，否则毛玻璃无意义
  - 注意文字对比度，**只用于少数浮层，不要全页铺满**

## 4. Neubrutalism（新野兽派）
- 气质：有个性、玩味、年轻
- 对标：Gumroad、Figma 社区插件页
- 适合：独立开发者产品、创意工具、面向年轻人的应用
- 参数：
  - 2–3px 纯黑边框；硬阴影 4px 4px 0 #000（无模糊）
  - 高饱和撞色（马卡龙或亮色）+ 米白/纯白底
  - 字体粗壮，按钮点击时阴影"压下去"

## 5. Clean Corporate / 经典极简白
- 气质：可信赖、亲和、专业
- 对标：Stripe、Notion
- 适合：支付/金融、文档工具、企业官网、教育类
- 参数：
  - 白底 #FFFFFF + 冷灰辅助底 #F8FAFC；文字 #0F172A / #475569
  - 大量留白；柔和的大范围弥散阴影（如 0 10px 40px rgba(15,23,42,0.06)）
  - 圆角 8–12px；单一主色，克制使用

## 6. 阅读友好 / Editorial（内容阅读型）
- 气质：安静、专注文字
- 对标：Notion 文档页、优质博客
- 适合：小说/文章阅读与写作工具、知识库
- 参数：
  - 正文宽度 ≤ 68–72 个字符（中文约 30–36 字/行），行高 1.7–1.9
  - 暖白或柔灰背景，护眼；可提供深色/护眼多档主题
  - 装饰几乎为零，层级靠字号与间距建立

## 7. 企业中后台（Ant Design 风）
- 气质：严谨、高效、信息密度大
- 对标：Ant Design、Tabler
- 适合：管理系统、数据密集型业务
- 参数：
  - 8px 栅格；表格紧凑行高 40–48px；状态用语义色（成功/警告/错误）
  - 主色一个，其余全部中性灰

## 选风格的决策提示
- 用户说"高级、科技感" → 优先 1（Linear）；要动效冲击力 → 加 Magic UI / Aceternity 的效果
- 用户说"年轻、好玩" → 优先 4
- 用户说"专业、可信" → 优先 5
- 用户说"做给自己用的工具" → 优先 1 或 5，克制最重要
- 阅读/写作类产品 → 优先 6，再叠加 1 或 5 的外壳
- 手机端产品 → 圆角偏大、触控区域 ≥ 44px、底部导航，风格取 5 或 2 的轻量版
