# 反模板清单

这些是 AI 生成页面的典型特征。**若简报里出现，必须有明确理由，否则替换。**

1. 紫蓝渐变背景，或用渐变文字当标题装饰
2. 内容切成一排完全一样的圆角卡片 + 同样的灰阴影，所有元素同一个圆角
3. 每个标题上方都加全大写、字距很开的小标签（眉标）
4. 标题里只把一个词换颜色或斜体来"强调"
5. 无意义的编号 01 / 02 / 03（内容并非真步骤序列时）
6. 每个区块都"淡入 + 上滑"，每张卡片都悬停浮起
7. 首屏默认是"大数字 + 小标签 + 渐变点缀"
8. 奶油底 + 衬线大标题 + 陶土橙（已泛滥）
9. 近黑底 + 单一荧光绿或亮橙（已泛滥）
10. 链接按钮后机械加"→"，信息用"A · B · C"圆点串联
11. 占位文案、假头像、假好评

## 正确做法
- 从产品所在行业的真实语境找视觉语言：驾考软件参考交通标识的色彩与图形，小说写作工具参考纸张与排版——而不是套通用模板
- 字体是性格的主要来源：认真选 1–2 个字体家族，建立明确的字号层级
- 删减比添加更重要：交付前"拿掉一件配饰"，去掉一个多余装饰
