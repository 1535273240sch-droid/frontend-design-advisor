# 反 AI 模板与常见廉价感黑名单 (Anti-AI Cliché Rules)

## 一、 色彩与光影黑名单
1. 禁用“AI 紫蓝霓虹渐变字”：严禁对每个大标题套用 from-indigo-500 via-purple-500 to-pink-500；优先用纯色高对比或同色系明度微渐变。
2. 禁用纯黑 #000000 配亮灰实心框 #374151：深色模式必须改用曜石深灰（#08090A）+ rgba(255,255,255,0.07) 半透明细框。
3. 禁用高饱和纯色实心状态标签：状态 Tag 统一采用 12% 透明度背景 + 20% 透明度细边框 + 高明度同色系文字。
4. 禁用脏黑单层阴影：浅色模式必须使用多层低透明度弥散阴影或 1px 环绕描边影。

## 二、 布局与结构黑名单
5. 禁用“三等分居中图标卡片”套路：改用非对称 Bento Grid（7:5 + 4:8），并在卡片内放入真实微缩 UI 预览（Mini UI Mockup）。
6. 禁用“内外同圆角”几何错误：严格执行 R_inner = R_outer - Padding。
7. 禁用无边界通栏超长正文：正文段落宽度不得超过 70ch。
8. 禁用超过 2 层的“套娃卡片”：内部子模块通过留白、1px 分割线或微弱背景明度差区分。

## 三、 排版、文案与交互黑名单
9. 禁用非等宽数字跳动：所有数字、价格、百分比、计时器强制加 tabular-nums。
10. 禁用“功能一 / 极速高效 / 赋能未来”等假文案：按钮与列表数据必须贴合真实行业语境。
11. 禁用 transition-all duration-300 ease-in-out 全局泛滥：精确指定过渡属性并将时长压缩至 150ms。
12. 禁用“大幅度悬浮上跳”（hover:-translate-y-2 shadow-2xl）：卡片 Hover 仅做边框提亮与背景微变。
