# 反 AI 模板清单

这些是"AI 生成页面"最常见的特征。它们不是绝对禁止，但**如果简报里出现，必须有明确理由**，否则替换。

1. 紫蓝渐变背景 / 渐变色文字标题当默认装饰
2. 内容被切成一排完全一样的圆角卡片 + 同样的灰色阴影，所有元素同一个圆角
3. 每个标题上方都加一个全大写、字距很开的小标签（eyebrow）
4. 标题里只把一个词换颜色或斜体来"强调"
5. 无意义的编号 01 / 02 / 03（内容并非真正的步骤序列时不要用）
6. 每个区块都做"淡入 + 上滑"，每张卡片都有 hover 浮起
7. 首屏默认是"大数字 + 小标签 + 渐变点缀"
8. 奶油底色 + 衬线大标题 + 陶土橙强调色（已经泛滥）
9. 近黑底色 + 单一荧光绿/亮橙强调色（已经泛滥）
10. 链接和按钮文字后面机械地加 "→"，信息用 "A · B · C" 圆点串联
11. 占位文案、假头像、假好评

## 做法
- 先从产品所在行业的真实语境找视觉语言（如驾考软件应参考交通标识的色彩与图形，小说写作工具应参考纸张与排版），而不是套通用模板。
- 字体是性格的主要来源：认真选 1–2 个字体家族，建立明确的字号层级。
- 删减比添加更重要：在交付前，"拿掉一件配饰"——去掉一个多余的装饰。
