# 交付前质量清单（逐条自检）

## 视觉
- [ ] 所有颜色来自设计变量，没有散落的硬编码色值
- [ ] 字号层级清晰（标题/小标题/正文/辅助文字），不超过 5 档
- [ ] 间距遵循统一栅格（4px 或 8px 倍数）
- [ ] 圆角、边框、阴影与简报一致，层级之间有区分
- [ ] 全页只有一处"记忆点"，其余克制

## 交互与状态
- [ ] 按钮/链接/输入框有悬停、键盘聚焦可见、禁用三种状态
- [ ] 每个数据区域都有加载中、空状态、出错状态
- [ ] 空状态与错误提示告诉用户"发生了什么、下一步怎么做"
- [ ] 同一操作全程用词一致（按钮叫"发布"，提示就叫"已发布"）

## 适配与可访问性
- [ ] 手机、平板、电脑宽度下都正常，表格/代码块在自身容器内横向滚动
- [ ] 文字与背景对比度达标（正文至少 4.5:1）
- [ ] 尊重系统"减少动效"设置
- [ ] 移动端触控目标 ≥ 44px
- [ ] 深浅色主题（如简报要求）都检查过

## 中文场景
- [ ] 字体栈含中文回退，如：-apple-system, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif
- [ ] 中文正文行高约 1.7，长文本行宽约 30–36 字/行
- [ ] 不依赖国内访问不稳定的外链资源

## 工程
- [ ] 能一条命令安装并运行，README 写清步骤
- [ ] 没有控制台报错和未使用的依赖
- [ ] 文案是真实内容，没有占位文本或"功能一 / 功能二"
