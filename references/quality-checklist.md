# 交付前大厂级 Design QA 自检清单 (4 维 16 项)

## 维度一：表面海拔与光影精度
- [ ] 1. 零硬编码色值：所有背景、文字、边框均通过 CSS 变量或主题 Token 引用。
- [ ] 2. 四层海拔清晰：明确区分 Canvas、Surface-1、Surface-2 与 Glass 浮层。
- [ ] 3. 边框与内高光细腻：深色模式使用 rgba(255,255,255,0.07) 细框与 inset 0 1px 顶部微高光；浅色模式使用多层环境影。
- [ ] 4. 主色克制（≤10% 法则）：品牌强调色仅出现在核心主按钮、激活指示器和关键数据点。

## 维度二：光学排印与几何对齐
- [ ] 5. 标题负向字距：≥24px 大标题已设置 -0.02em ~ -0.035em 紧凑字距。
- [ ] 6. 数字全部等宽：所有数据卡片、价格、计数器、表格和时间均已启用 tabular-nums。
- [ ] 7. 同心圆角严丝合缝：所有嵌套容器满足 R_inner = R_outer - Padding。
- [ ] 8. 图标与文字光学对齐：全文图标线条粗细统一（1.5px 或 1.75px），与文字垂直中心对齐。

## 维度三：空间节奏与反模板化
- [ ] 9. 宏观留白 ≥ 3 倍微观留白：模块间距（64px+）、卡片内边距（20–28px）与元素间距（8–12px）层次分明。
- [ ] 10. 零“三等分图标口号卡”：采用非对称 Bento 比例、暴露网格线或内嵌真实微缩交互组件。
- [ ] 11. 唯一视觉记忆点突出：全站有且仅有 1 处重度打磨的招牌视觉/交互区。
- [ ] 12. 100% 真实领域文案：零 Lorem ipsum、零“功能一/二/三”、零破图。

## 维度四：交互动力学与全状态覆盖
- [ ] 13. 瞬时清脆反馈：高频动画时长 140ms–180ms，使用 cubic-bezier(0.22, 1, 0.36, 1) 或弹簧，带 active:scale-[0.98]。
- [ ] 14. 五态齐全：具备 Default、Hover、Active、Focus-Visible（键盘聚焦环）及 Disabled / Loading 状态。
- [ ] 15. 空状态与边界优雅：列表为空有精致 Empty State；长文本有 truncate / line-clamp 保护。
- [ ] 16. 响应式无横向溢出：桌面宽屏（1440px）与移动端（375px）均无意外横向滚动条或文字重叠。
